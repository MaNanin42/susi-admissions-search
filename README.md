# 수시 입결 검색기 V11.0.0 공개용

2027학년도 수시 상담을 위한 단일 HTML 검색 도구입니다. GitHub Pages에는 학생 개인정보를 제거한 공개본만 배포합니다.

## 사이트

- 공개 주소: https://mananin42.github.io/susi-admissions-search/ (V11.0.0)
- 배포 방식: GitHub Pages, `main` 브랜치 루트

## 기능

- 대학·모집단위별 교과/종합 입결 검색
- 상단의 `수시 입결 검색`·`입학처 모아보기`·`계약학과 모아보기`·`2028 대입 탐색` 작업 탭 전환
- 현재 데이터의 대학·캠퍼스 223개를 권역별로 모아보기
- 네이비·화이트 기반 고대비 UI와 권역별 파스텔 구분
- 수능최저 참고 판정과 수동 등급 입력
- 2027 대교협 자료 기반 계약학과 35개·첨단학과 217개 모집단위 필터와 출처 페이지 배지
- 계약학과 배지에서 협약기관·지원·선발·의무조건 상세정보로 바로 이동
- 계약학과 상세에서 현재 기준선의 교과·종합 전형별 50%·70% 입결과 미공개 상태 확인
- 계약학과 탭의 내신·범위 입력과 검색 탭 값 동기화, 범위 해당 학과 카드의 밝은 적색 강조
- 공식 대학 웹자료가 확인된 계약학과 12개는 선발·고용유지·교육과정 조건과 출처 링크 보완
- 2028 시행계획 확인 후보와 추가조사 필요 후보를 구분하는 조건별 대학·학과·전형 탐색
- 특별조건 후보와 일반 후보를 각각 최대 10개로 분리하고 지역·입결범위·면접·여대 제외 필터 유지
- 상담 후보 담기·비교·인쇄
- 학생 모의고사 원본, 반·번호별 성적, 자동 성적 불러오기는 포함하지 않음

`입학처 모아보기`는 현재 데이터의 대학 목록과 캠퍼스 표기를 정리하고, `data/admissions-office-links.json`에서 2027학년도 수시 모집요강 주소가 검증된 대학만 새 창 링크로 활성화합니다. 2026-08-23 기준 서울 41개, 경인권 46개, 제주권 2개, 강원권 10개, 충청권 48개, 전라권 28개, 경상권 48개로 총 223개 대학·캠퍼스를 모두 연결했습니다. 221개는 HTTPS이며, 칼빈대와 중원대는 입학처가 제공하는 공식 주소가 HTTP인 예외입니다. 루터대는 대학 입학처의 HTTPS 인증서 문제로 대입정보포털이 제공하는 2027학년도 원문을, 공군사관학교는 공식 사이트의 DNS 장애로 경기도교육청 학교 홈페이지가 제공하는 동일 모집요강 사본을 연결하고 버튼에 출처를 구분 표시합니다. 확인되지 않은 URL은 추측해서 연결하지 않습니다.

2027학년도부터 강원대학교 통합 입학처가 춘천·삼척(도계 포함)과 강릉·원주 모집요강을 함께 공고하므로, 현재 입결 데이터의 `강원대`, `강원대(삼척)`, `국립강릉원주대` 표기는 유지하면서 같은 공식 통합 공지로 연결합니다.

`학과 특성` 필터는 대교협의 2027학년도 계약학과·첨단학과 현황을 현재 입결 기준선과 대조해 대학과 모집단위가 유일하게 정확 일치한 항목만 사용합니다. PDF 표 393행 중 계약학과 35개, 첨단학과 217개 모집단위를 공개 태그로 연결했으며, 단과대학명 포함·복수 학과 병기·군/성별 분리·개편 명칭 등 138행은 자동 연결하지 않았습니다. 계약학과 배지는 `계약학과 모아보기`의 해당 상세정보로 이동하고, 첨단학과 배지는 출처 페이지를 툴팁으로 표시합니다.

`계약학과 모아보기`는 연결이 검증된 35개 모집단위만 대상으로 유형, 협약기업·기관, 등록금·장학금, 별도 선발·채용 조건, 의무근무·복무, 주의사항을 대교협 자료 범위에서 요약합니다. 같은 대학·모집단위의 현재 입결 기준선도 함께 연결해 23개 모집단위의 공개 입결 35건과 미공개 전형 18건을 구분 표시합니다. 계약학과 탭에서 내신과 ±범위를 입력하면 검색 탭의 값도 함께 바뀌며, 50%·70% 입결 중 하나가 범위에 들어오는 학과 카드를 밝은 적색으로 강조합니다. 동일 키의 원본 행이 여러 개인 경우 중복을 제거하되 서로 다른 값은 `복수 원본`으로 남깁니다. 빈 계약조건은 없는 조건으로 단정하지 않고 `자료에 명시되지 않음`으로 표시합니다. 공식 웹자료를 추가 확인한 가천대 5개, 경일대 4개, 유원대 3개에는 확인일과 공식 링크를 함께 표시했습니다. 특정 기업 인원이나 세부 계약과정만 기재된 경우 학과 전체에 적용되지 않을 수 있으며, 이 화면은 모집요강·채용 보장을 대신하지 않습니다.

`2028 대입 탐색`은 `modules/admission-2028` 안에 UI 원본·데이터·빌드·검증 파일을 함께 둔 독립 모듈입니다. 처음 탭을 열 때만 로드하고 iframe을 다시 만들지 않아 탭 전환 중 입력이 유지됩니다. 현재 탐색 분모 21,720개 중 공식 확인 20,153개와 `추가조사 필요` 1,567개를 구분하며, 보관 처리된 1,031개는 검색에서 제외합니다. 학생 입력은 현재 페이지 메모리에만 존재하고 서버 저장·외부 전송·AI API·텔레메트리·브라우저 영구 저장소를 사용하지 않습니다.

## 개발 구조

현재 배포 HTML에서 데이터와 템플릿을 분리해 재구성 가능한 기준선을 복구했습니다.

```text
index.html                         # 배포 산출물
src/index.template.html            # HTML/JS/CSS 템플릿
data/baseline/admissions.json      # 입결 5,863행
data/baseline/suneung-minimum.json # 수능최저 3,576건
data/program-tags.json             # 계약·첨단학과 검증 태그 252개
data/contract-program-details.json # 계약학과 35개 상세조건 요약
scripts/build.mjs                  # 재구성·동등성 검사
scripts/generate-program-tags.py   # 로컬 대교협 PDF 재추출·정확 매핑
scripts/validate-public.mjs        # 공개본 종합 검사
modules/admission-2028/            # 2028 탐색 UI·데이터·재생성·통합 검증
scripts/audit-source.py            # 공식 원본 대조
requirements.txt                   # 원본 대조용 Python 의존성
docs/HANDOFF.md                    # 후속 작업 인계서
```

## 검증

```powershell
node scripts/build.mjs --check
node modules/admission-2028/scripts/build.mjs --check
node modules/admission-2028/scripts/verify.cjs
node scripts/validate-public.mjs
```

종합 검사는 권역별 대학·캠퍼스 223개와 모집요강 링크 223개, 계약·첨단학과 태그 252개, 계약학과 상세정보 35개와 그중 입결 공개 모집단위 23개, 공식 웹 보완 12개를 기준 데이터와 대조합니다. 내신 2.50±0.30과 4.50±0.30의 강조 학과 수를 회귀 표본으로 확인합니다. 프로그램 태그 원본 PDF까지 다시 확인할 때는 로컬 원본이 있는 환경에서 `python scripts/generate-program-tags.py`를 실행합니다.

공식 XLSX/PDF 원본을 다시 감사할 때만 프로젝트의 `.venv`를 활성화하고 `requirements.txt`를 설치합니다. `.venv`와 원본 파일은 공개·커밋 대상에서 제외됩니다.

## 최신 공식 원본

원본 XLSX/PDF는 인접한 로컬 진로진학자료집 폴더에 보관하고 공개 저장소에는 커밋하지 않습니다. 위치와 SHA-256은 `sources/source-manifest.json`에 기록했습니다.

V11.0.0의 기존 입결 검색 기준 데이터는 V10.6에서 검증한 5,863행을 그대로 사용합니다. 260813 XLSX에는 이 대학·모집단위 키가 모두 남아 있고 신규 키 134개가 있습니다. 기존 5,863행 중 5,807행은 값까지 일치하며, 다른 56행 중 51행은 동국대 공식 보정 항목입니다. 신규 항목과 나머지 차이는 유실된 연결·보정 규칙을 복구한 뒤 후속 데이터 전용 버전에서 반영하며, 현재 V11.0.0에는 아직 적용하지 않았습니다.

자세한 상태와 후속 절차는 `docs/HANDOFF.md`를 확인하십시오.
