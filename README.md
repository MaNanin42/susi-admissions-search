# 수시 입결 검색기 V10.6 공개용

2027학년도 수시 상담을 위한 단일 HTML 검색 도구입니다. 내부용 V10.6을 기준으로 공개에 필요한 기능만 분리했습니다.

## 공개 범위

- 대학·모집단위별 교과/종합 입결 검색
- 수능최저 참고 판정과 수동 등급 입력
- 상담 후보 담기·비교·인쇄
- 학생 모의고사 원본 파일, 반·번호별 성적 데이터, 자동 불러오기 기능은 포함하지 않음

## 실행

index.html을 최신 Chrome 또는 Edge에서 열면 됩니다. 별도 서버나 설치가 필요하지 않습니다.

## 주의

입결과 수능최저 표시는 상담 참고용입니다. 대학의 최종 모집요강과 공식 발표 자료를 반드시 함께 확인하십시오.

## 검증

node scripts/validate-public.mjs
