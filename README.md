## 개발 구조

현재 배포 HTML에서 데이터와 템플릿을 분리해 재구성 가능한 기준선을 복구했습니다.

```text
index.html                         # 배포 산출물
src/index.template.html            # HTML/JS/CSS 템플릿
data/baseline/admissions.json      # 입결 5,863행
data/baseline/suneung-minimum.json # 수능최저 3,576건
data/program-tags.json             # 계약·첨단학과 검증 태그 252개
data/contract-program-details.json # 계약학과 35개 상세조건 요약
scripts/build.mjs                  # 재구성·동등성 검사
scripts/generate-program-tags.py   # 로컬 대교협 PDF 재추출·정확 매핑
scripts/validate-public.mjs        # 공개본 종합 검사
modules/admission-2028/            # 2028 탐색 UI·데이터·재생성·통합 검증
scripts/audit-source.py            # 공식 원본 대조
requirements.txt                   # 원본 대조용 Python 의존성
docs/HANDOFF.md                    # 후속 작업 인계서
```

## 최신 공식 원본

원본 XLSX/PDF는 인접한 로컬 진로진학자료집 폴더에 보관하고 공개 저장소에는 커밋하지 않습니다. 위치와 SHA-256은 `sources/source-manifest.json`에 기록했습니다.

V11.0.0의 기존 입결 검색 기준 데이터는 V10.6에서 검증한 5,863행을 그대로 사용합니다. 260813 XLSX에는 이 대학·모집단위 키가 모두 남아 있고 신규 키 134개가 있습니다. 기존 5,863행 중 5,807행은 값까지 일치하며, 다른 56행 중 51행은 동국대 공식 보정 항목입니다. 신규 항목과 나머지 차이는 유실된 연결·보정 규칙을 복구한 뒤 후속 데이터 전용 버전에서 반영하며, 현재 V11.0.0에는 아직 적용하지 않았습니다.
