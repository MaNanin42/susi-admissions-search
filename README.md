# 수시 입결 검색기 V10.7.1 공개용

2027학년도 수시 상담을 위한 단일 HTML 검색 도구입니다. GitHub Pages에는 학생 개인정보를 제거한 공개본만 배포합니다.

## 사이트

- 공개 주소: https://mananin42.github.io/susi-admissions-search/
- 배포 방식: GitHub Pages, `main` 브랜치 루트

## 기능

- 대학·모집단위별 교과/종합 입결 검색
- 상단의 `수시 입결 검색`·`입학처 모아보기` 작업 탭 전환
- 현재 데이터의 대학·캠퍼스 223개를 권역별로 모아보기
- 네이비·화이트 기반 고대비 UI와 권역별 파스텔 구분
- 수능최저 참고 판정과 수동 등급 입력
- 상담 후보 담기·비교·인쇄
- 학생 모의고사 원본, 반·번호별 성적, 자동 성적 불러오기는 포함하지 않음

`입학처 모아보기`는 현재 데이터의 대학 목록과 캠퍼스 표기를 정리하고, `data/admissions-office-links.json`에서 2027학년도 수시 모집요강 주소가 검증된 대학만 새 창 링크로 활성화합니다. 2026-08-23 기준 서울 41개, 경인권 46개, 제주권 2개, 강원권 10개, 충청권 48개, 전라권 28개, 경상권 48개로 총 223개 대학·캠퍼스를 모두 연결했습니다. 221개는 HTTPS이며, 칼빈대와 중원대는 입학처가 제공하는 공식 주소가 HTTP인 예외입니다. 루터대는 대학 입학처의 HTTPS 인증서 문제로 대입정보포털이 제공하는 2027학년도 원문을, 공군사관학교는 공식 사이트의 DNS 장애로 경기도교육청 학교 홈페이지가 제공하는 동일 모집요강 사본을 연결하고 버튼에 출처를 구분 표시합니다. 확인되지 않은 URL은 추측해서 연결하지 않습니다.

2027학년도부터 강원대학교 통합 입학처가 춘천·삼척(도계 포함)과 강릉·원주 모집요강을 함께 공고하므로, 현재 입결 데이터의 `강원대`, `강원대(삼척)`, `국립강릉원주대` 표기는 유지하면서 같은 공식 통합 공지로 연결합니다.

## 개발 구조

현재 배포 HTML에서 데이터와 템플릿을 분리해 재구성 가능한 기준선을 복구했습니다.

```text
index.html                         # 배포 산출물
src/index.template.html            # HTML/JS/CSS 템플릿
data/baseline/admissions.json      # 입결 5,863행
data/baseline/suneung-minimum.json # 수능최저 3,576건
scripts/build.mjs                  # 재구성·동등성 검사
scripts/validate-public.mjs        # 공개본 종합 검사
scripts/audit-source.py            # 공식 원본 대조
requirements.txt                   # 원본 대조용 Python 의존성
docs/HANDOFF.md                    # 후속 작업 인계서
```

## 검증

```powershell
node scripts/build.mjs --check
node scripts/validate-public.mjs
```

종합 검사는 권역별 대학·캠퍼스 223개가 기준 데이터와 정확히 일치하는지, 검증된 수시 모집요강 링크가 223개인지, 공공기관 대체 원문 2건의 출처 라벨과 공식 HTTP 예외 2건이 정확한지 함께 확인합니다.

공식 XLSX/PDF 원본을 다시 감사할 때만 프로젝트의 `.venv`를 활성화하고 `requirements.txt`를 설치합니다. `.venv`와 원본 파일은 공개·커밋 대상에서 제외됩니다.

## 최신 공식 원본

원본 XLSX/PDF는 인접한 로컬 진로진학자료집 폴더에 보관하고 공개 저장소에는 커밋하지 않습니다. 위치와 SHA-256은 `sources/source-manifest.json`에 기록했습니다.

V10.7.1 공개본의 입결 기준 데이터는 V10.6의 검증된 5,863행을 그대로 사용합니다. 260813 XLSX에는 이 대학·모집단위 키가 모두 남아 있고 신규 키 134개가 있습니다. 기존 5,863행 중 5,807행은 값까지 일치하며, 다른 56행 중 51행은 동국대 공식 보정 항목입니다. 신규 항목과 나머지 차이는 유실된 연결·보정 규칙을 복구한 뒤 V10.8 이상에서 반영하며, 현재 V10.7.1에는 아직 적용하지 않았습니다.

자세한 상태와 후속 절차는 `docs/HANDOFF.md`를 확인하십시오.

## 주의

입결과 수능최저 표시는 상담 참고용입니다. 대학의 최종 모집요강과 공식 발표 자료를 반드시 함께 확인하십시오.
