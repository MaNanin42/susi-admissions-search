# cutoff 점수·등급 전수조사 (2026-10-10)

현재 cutoff.co.kr 공개 수시자료를 기준으로 표시 단위를 분리했다. 대학 공식 원문 전체를 다시 검증했다는 의미는 아니다.

- 조사: 204개 대학·캠퍼스, 전체 연도 84,533행, 2026학년도 24,140행.
- 점수형 분리: 2026학년도 130개 대학·캠퍼스 10,550행. 만점이 양수로 공개되었거나, 등급컷 없이 환산컷만 있는 경우다.
- 등급과 환산점수가 함께 있어도 만점 미공개이면 등급은 등급자료로 유지하고 환산점수는 상세 참고로 둔다. 1이라는 값만으로 점수형·오류라고 판정하지 않는다.
- 분리는 안전한 표시 정책이다. 해당 대학의 등급자료가 모두 잘못되었다는 판정이 아니다. 서로 다른 만점의 점수도 통합 순위로 비교하지 않는다.

## 검색기 반영

- 2028 탐색의 실제 생성 자료에서 2026 점수형 6,176행을 등급 범위·등급 숫자 정렬에서 제외했다.
- 첫 탭의 점수형 전형 슬롯 4,001개와 계약학과 과거 입결 2개를 분리했다. 데이터셋 사이에 중복이 있으므로 합산하지 않는다.
- 목록·상세·후보 비교·인쇄 문자열에 환산점수와 만점을 표시하고 원문 등급은 참고로 보존한다.
- 원본 JSON 3개는 최초 감사 SHA-256과 동일하다. 2027 최종 지원현황 연결은 유지했다.

## 미연결과 한계

- 전국 자료: 현재 원문 연결 14,776행, 연결키 없는 자료 7,944행, 키 불일치 29행, 중복 모호 2행. 연결키 없는 자료는 주로 시행계획만 있는 행이다.
- 첫 탭: 현재 원문 연결 8,555슬롯, 미연결 3,503슬롯, 중복 모호 1슬롯. 계약학과: 연결 14개, 미연결 2개.
- 미연결은 기준 미확인으로 표시하고 공통 등급 비교에서 제외했다. 원문을 임의 수정하거나 타 전형 자료로 채우지 않았다.
- 2026 원문 173행에 범위 밖 등급 또는 만점 초과 점수 점검 표시가 있다. 가산점·산출방식 원문 확인 전에는 오류로 단정하지 않는다.
- 브라우저에서 대표 사례의 단위 표시를 확인했고 자동검증으로 모든 연결 점수행의 필터·정렬 제외와 원본 보존을 확인했다. 실물 인쇄·배포는 하지 않았다.
