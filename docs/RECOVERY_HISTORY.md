교사가 학생의 내신 기준 등급과 수능 예상 등급을 입력해 2027학년도 수시 모집단위를 검색하고, 교과·종합 입결과 수능최저 참고 상태를 함께 검토하는 정적 상담 도구다. 일반적인 15.6인치·16인치 노트북과 24인치 이상 16:9 모니터를 기준으로 설계됐으며 모바일 화면은 우선 대상이 아니다.

## V10.7.2 계약·첨단학과 연동 결정

2026-08-30 대교협의 2027학년도 계약학과 15쪽과 첨단학과 62쪽 자료를 새 보조 원본으로 등록했다. 표 393행을 현재 입결 5,800개 대학·모집단위 키와 대조했으며, 공백·문장부호를 제외한 학과명이 대학 후보 안에서 유일하게 정확 일치한 모집단위만 공개 태그로 연결했다.

- 계약학과: 원본 77행 중 35개 모집단위 연결, 42행 검토 보류
- 첨단학과: 원본 316행 중 220행이 정확 일치하며 반복 페이지를 합쳐 217개 모집단위 연결, 96행 검토 보류
- 공개 태그 합계: 252개 모집단위
- 기존 입결 5,863행, 대학·모집단위 키 5,800개, 수능최저 3,576건은 변경하지 않음
- 계약학과는 채용 보장을 뜻하지 않으며 첨단학과 자료도 입결·경쟁률로 사용하지 않음
- 원본 PDF는 로컬 자료집에만 두고 공개 저장소에는 포함하지 않음

연결된 계약학과 35개에는 별도 상세 레이어를 추가했다. 상단 `계약학과 모아보기`에서 대학·학과·협약기관 검색과 유형 필터를 제공하고, 검색 결과의 계약학과 배지를 누르면 같은 대학·모집단위 상세로 이동한다. 상세정보는 협약기관, 지원, 별도 선발·채용, 의무근무·복무, 주의사항을 분리하며 원문에 없는 항목은 `자료에 명시되지 않음`으로 남긴다. 중앙대 산업보안학과와 백석대 학부 단위처럼 일부 기업 인원·세부 과정에만 적용될 수 있는 경우에는 학과 전체 조건으로 확대하지 않도록 별도 주의를 표시한다.

계약학과 상세에는 기존 입결 기준선도 같은 대학·모집단위 키로 연결했다. 35개 중 23개 모집단위에 수치가 있으며 전형 단위로 공개 35건, 미공개 18건이다. 동일 키가 여러 원본 행에 존재하면 완전히 같은 전형·수치는 중복 제거하고 서로 다른 수치는 모두 보존해 `복수 원본`으로 표시한다. 입결 미공개 전형은 숫자를 추정하지 않는다.

계약학과 탭에도 학생 내신과 ±범위 입력을 추가해 검색 탭의 값과 양방향으로 동기화했다. 점수형·특수 지표·미공개 값은 제외하고, 일반 등급형 50% 또는 70% 입결 중 하나가 지정 범위에 들어오는 학과만 밝은 적색 카드와 `성적 범위 해당` 배지로 강조한다.

대교협 현황에 비어 있던 조건은 공식 대학 웹자료로 1차 보완했다. 가천대 5개 학과는 2026년 입학생부터 적용되는 4년 교육과정·기업 변경 불가·자발적 퇴사 시 제적과 2027 참여기업 현황을, 경일대 4개 학과는 2027 학생부종합 1단계·채용기업 면접·채용확약서 절차를, 유원대 3개 학과는 졸업 시까지 고용계약 유지와 자발적 퇴직 시 제적 조건을 반영했다. 각 항목에 공식 URL과 확인일을 보존하며, 웹자료에도 없는 의무기간은 추정하지 않는다.
