# 복구 이력과 주요 결정

## V10 계열의 목적

교사가 학생의 내신 기준 등급과 수능 예상 등급을 입력해 2027학년도 수시 모집단위를 검색하고, 교과·종합 입결과 수능최저 참고 상태를 함께 검토하는 정적 상담 도구다. 일반적인 15.6인치·16인치 노트북과 24인치 이상 16:9 모니터를 기준으로 설계됐으며 모바일 화면은 우선 대상이 아니다.

## V10.6에서 확인된 핵심 기능

- 대학·모집단위, 계열, 권역, 전형 유형, 입결 공개 여부 검색
- 교과/종합 50%·70% 입결 표시
- 수능최저 자동 참고 판정과 모집요강 확인 상태 분리
- 상담 후보 담기, 별도 후보 비교 탭, 후보 인쇄
- 동국대 교과 공식 자료 보정값과 NAVI 값 분리

## 공개본 분리 결정

내부 V10.6에는 학생 모의고사 성적 240건을 반·번호로 불러오는 기능이 있었지만 GitHub 공개 시 모두 제거했다. 공개본에는 수능 등급 수동 입력만 남겼다. 현재 저장소와 Pages는 공개본만 포함한다.

## 복구 기준

기존 로컬 작업 폴더가 소실되어 GitHub Pages에 배포된 커밋 `6b81660`을 기준선으로 다시 받았다. 이 기준선에서 입결 데이터와 수능최저 데이터를 분리했고, 템플릿 빌드가 기존 HTML과 동일함을 검증했다.
