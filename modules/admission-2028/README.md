# 2028 대입 탐색 모듈

V12 개편: 통합 화면의 두 번째 탭입니다. 전체 모집정보는 대학·학과·전형 검색과 30개씩 탐색을 지원하고, 조건 연결 후보의 기존 각 10개 제한은 유지합니다. 명시적 정시 항목과 별도 수록 계약학과는 제외합니다. 5등급제 학생 성적과 선택형 과거 입결 필터를 분리했습니다. `data/recommended-courses.json`과 `scripts/course-ui.js`는 권장이수과목 프로젝트 공개 표 770행과 대교협 2028 자료집 추가 144행을 합친 914행·정책 45행의 조회 기능입니다. 기존 원본 레코드 수와 확인율은 변경하지 않았으므로 아래 분모는 검색 결과 수가 아니라 기초자료 범위입니다.

수시 입결 검색기의 `2028 대입 탐색` 탭에서 한 번만 지연 로드되는 독립 모듈입니다. 탭을 전환해도 iframe을 다시 만들지 않으므로 입력 상태가 페이지 메모리에 유지됩니다.

## 기준선

- 전체 데이터 레코드: 22,751개
- 2028 현재 탐색 분모: 21,720개
- 2028 공식 확인: 20,153개
- 추가조사 필요: 1,567개
- 보관 처리: 1,031개 (`legacyDisposition2028`, 검색 제외)
- 과거 입결 원본 행: 16,412개
- 확인율: 92.7854511970534%

`researchStatus="needs-research"`인 항목은 공식 확인으로 승격하지 않으며, 화면에서 `추가조사 필요`와 `과거 입결 참고`로 표시합니다.

## 구조와 명령

```text
index.html                 # 정적 실행 파일
src/index.template.html    # 데이터·UI 삽입 전 템플릿
data/nationwide.json       # 현재 2028 탐색 데이터
data/verification.json     # 통합 검증 결과
scripts/real-ui.js         # 후보·지원자격·필터 로직
scripts/grade-ui.js        # 과목별 내신 입력 로직
scripts/build.mjs          # 템플릿에서 index.html 재생성
scripts/verify.cjs         # 통합 회귀 검사
```

```powershell
node modules/admission-2028/scripts/build.mjs --check
node modules/admission-2028/scripts/verify.cjs
```

학생 입력은 서버·외부 API·텔레메트리·브라우저 영구 저장소로 전송하거나 저장하지 않습니다. `data/nationwide.json`에는 공개 입시자료만 포함하며, 로컬 원본 CSV의 절대경로는 제거하고 SHA-256만 보존합니다.

## 상담 기능 개선 (2026-10-03 배포 대상)

- 결과에서 후보를 담아 전형·입결·모집인원·면접·수능최저·공식 근거를 비교하고 상담지로 인쇄합니다. 후보함은 페이지 메모리만 사용하며 초기화·새로고침 시 지워집니다.
- 수능최저 상태를 없음/충족/미충족/판정 보류로 필터링합니다. 조건을 다시 적용하면 담은 후보의 판정도 갱신됩니다.
- `입결 없는 공식 후보`는 입결 범위를 적용하지 않고 나머지 선택 조건을 유지합니다. 기존 특별/일반 각 최대 10개 제한은 그대로입니다.
- 공식 출처에는 URL·근거 쪽수·검토일을 표시합니다. 검토일은 자료에 기록된 날짜이며 최신 모집요강 재확인을 대신하지 않습니다.
- 인쇄는 Chrome/Edge의 인쇄 기능을 사용합니다. 실제 프린터 출력은 별도 확인이 필요합니다.
